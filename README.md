# Broke But Functional — Survive the Month

A modular, React-based 30-day personal finance simulator engineered for runtime efficiency and zero layout shift.

## Architecture & Stack
- **Framework:** React + Vite (App Router equivalent)
- **State Management:** Zustand (Isolated DOM rendering)
- **Styling:** Tailwind CSS + Shadcn UI (Strict Semantic HTML & ARIA compliance)
- **Data Persistence:** LocalStorage API

## Deployment
Automated CI/CD pipeline integrated via Vercel.
